## 2026-11-05: Rested vs back-to-back follow-ups: backup goalies, and does the shot model price it? (NHL) [TEST] [CORRELATION]
- Question: after the pre-registered 2011-16 pass (rested team beat the no-vig close by +2.7 pts), (1) is it just backup goalies starting on back-to-backs, and (2) does the goalie-aware shot model already price it?
- Data / method: rules fixed and pushed first (`backtests/REST_B2B_FOLLOWUPS_PREREG.md`, commit 2285b19, 23:09 UTC). F1: 2,936 eligible b2b games 2012-22 (8 dropped, no goalie id), b2b team's actual goalie vs its season's most-used goalie (`derived/oos_games_g.csv.gz`). F2: 8,142 trusted games 2015-21 with model G1's `p_home_win_open` (`derived/gr_G1_pred_*.csv.gz`), 1,814 with exactly one team on a b2b. Script `dev/rest_b2b_followups.py`, output `dev/rest_b2b_followups_output.txt`. Both ran once. Same seasons as the parent test, so these are splits of seen games, not new data. Two tests, no multiple-testing correction.
- Result F1 (primary: gap when the b2b team starts its main goalie, win minus no-vig close): **STARTER +1.75 pts (SE 1.38, one-sided p = 0.103, n = 1,240); BACKUP +2.95 (SE 1.17, p = 0.006, n = 1,696); all +2.44.** By period: A 2012-16 starter +3.3 (p = 0.04, n = 644), backup +2.2 (n = 778); B 2017-22 starter +0.04 (n = 596), backup +3.6 (p = 0.012, n = 918). Difference backup - starter +1.2 pts (90% CI -1.8 to +4.2). The b2b team starts a backup in 54.7% (A) and 60.6% (B) of these games. Verdict by the pre-registered rule: **NOT SHOWN without backups** (p >= 0.05).
- Result F2 (primary: rest coefficient in a logistic of home win on logit(open) + logit(model) + rest advantage): **+0.102 (SE 0.052), one-sided p = 0.025: PASS, the model does not fully price it.** Reference, opener only: +0.138 (p = 0.003). Secondary, close + model: +0.070 (p = 0.087). Among the 1,814 b2b games, the rested side won 57.6% vs model 56.6%, open 54.5%, close 55.7%; win - model +0.9 pts (SE 1.1), win - open +3.0, win - close +1.9, model - open +2.1 (SE 0.1).
- Read: (1) Inconclusive, leaning "not only backups": starter games keep about 60% of the overall gap, but with 1,240 games (power about 57%) the starter gap is not significant, it is gone in 2017-22 (+0.04), and it cannot be told apart from the backup gap. Backup starts are the likeliest mechanism, not shown to be the only one. (2) The shot model already prices most of it: it leans +2.1 pts toward the rested team, about 70% of the 3.0-pt opener gap. What is left is about +0.9 pts directly (not significant); the regression pass (p = 0.025) is borderline, and it weakens against the close (p = 0.087). So a standalone "back the rested team" rule is mostly the same bets the model already makes, and the extra edge is about one point at most. Correlation only; neither test shows cause.
- Decision: nothing changes in live rules or alerts. The `state/rest_b2b_test.csv` log keeps running. Open ideas are in `research/IDEAS_AND_CHECKLIST.md` (split by rest days and road second night; rest as a model term, leave-one-season-out on 2012-22).
